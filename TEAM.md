Regular merge was used for all pull requests. The only exception is for the final submission pull request where a squash merge was used.

Merge methods:
1. merge -> Retains entire commit history, the branch and original dates.
2. squash and merge -> Omits the entire commit history and asks you to use a single commit message to descripe your feature/fix/change.
3. rebase and merge -> Re-rolls commit hashes and adds them linearly over main. Shows commit message but not branch history.
